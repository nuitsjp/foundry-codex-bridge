はじめる準備

Azure のモデルを Codex から使えるようにするために、4 つの項目を確認します。自動でできることは Bridge が行います。

…
Azure にサインイン
Azure CLI でサインインします。ブラウザーが開くので、そちらで承認してください。
…
利用する Azure リソースを選ぶ
Codex から使う Foundry / Azure OpenAI リソースを選びます。あとから設定で変更できます。
…
Node.js と npm
opencodex の実行に Node.js 18 以上が必要です。
…
opencodex（ocx）
Codex と Azure の間をつなぐローカルプロキシです。ユーザー領域に導入します。
…
バックグラウンドサービス
Windows にサービスとして登録します。登録時に「ユーザーアカウント制御」の確認が表示されます。
サインインするとブラウザーが開きます。
